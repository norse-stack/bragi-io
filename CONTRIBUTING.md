# Contributing to Bragi

Thank you for using Bragi. The most useful thing you can give the project right now is what you find when you use it.

## What helps most

- **Bug reports.** A document that parses wrongly is the best bug report there is. Tell us what you expected and what you got. If you can share the file, or a small one that shows the same problem, attach it; if you cannot, the output and a description of the layout still help.
- **Feature requests.** Say what you are trying to do, not only what you want added. The use case often points to a better answer than the feature first asked for.
- **Questions.** If something in the docs is unclear or missing, that is a documentation bug. Open an issue.

Open an issue at <https://github.com/norse-stack/bragi-io/issues>.

## Pull requests

**We are not accepting pull requests for now.**

Bragi is built by a very small team, and the parser's output is covered by frozen reference files that every change has to keep stable. Reviewing outside code against them properly takes more time than we have at this stage, and we would rather say so than leave your work unanswered.

This will change, and this file will say so when it does. Until then:

- A pull request may be closed without review. Please do not read that as a judgement of the work.
- If you have found a fix, describe it in an issue. A clear description of the cause is as valuable to us as the patch.
- Typo and documentation fixes are welcome as issues too.

## Forks

You are free to fork Bragi and change it under its licences. If you publish a changed version, give it a different name: see [TRADEMARKS.md](TRADEMARKS.md).

## Licensing of contributions

Bragi is licensed under MIT or Apache-2.0, at your option. Versions already published stay under those licences.

When we do open the project to code contributions, we will ask each contributor to sign a contributor agreement first. It will let you keep the copyright in your work and will give Amplify Technology the right to license it under any terms, including terms other than the current licences. We ask for this so that the project can change its licence for future versions without needing permission from every past contributor.

Ideas and suggestions you post in issues may be used in the project without obligation to you.

## Security

Please do not report a security problem in a public issue. Write to <hello@bragi-io.com>.
