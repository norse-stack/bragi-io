# Bragi name and logo policy

The code in this repository is open source under MIT or Apache-2.0. The names and logo are not part of that grant. Neither licence gives permission to use them, and this page says what is and is not fine.

"Bragi", "Bragi-io", "Norse Stack" and the Bragi logo are trademarks of Amplify Technology.

## The short version

Use the code however the licences allow. Use the name to talk about the project. Do not use the name for something that is not the project.

## Fine without asking

- Saying that your product uses, works with, or is built on Bragi.
- Writing about Bragi, teaching it, benchmarking it, reviewing it.
- Naming an integration so that it is clear which side is yours: "Acme connector for Bragi" is fine.
- Distributing unmodified builds of an official release under the Bragi name, for example in a package repository.

## Not fine

- **A fork or modified version under the Bragi name.** If you change the code and publish the result, give it a different name. You may say it is "based on Bragi" or "a fork of Bragi".
- A product, service, company or domain name that contains "Bragi" or is close enough to be confused with it.
- Offering a hosted service called Bragi, or in a way that suggests it is ours.
- Using the logo on your own product, or in a way that suggests we endorse it.

## Why

The licences let anyone take the code in any direction. The name is how a person knows which code they are running and who stands behind it. A parser that behaves differently under the same name hurts the people who rely on its output being stable.

If you are unsure, or want to do something this page does not cover, write to <hello@bragi-io.com>.
